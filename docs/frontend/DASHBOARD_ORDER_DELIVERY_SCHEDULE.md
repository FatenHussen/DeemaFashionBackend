بجانب **توصيل فوري** على الطلب، في خيار ثاني: **تحديد يوم ووقت التوصيل**.  
القيمة تظهر على كرت الطلب عند الزبون.  
ما إلها علاقة بجملة «التسليم خلال 3–5 أيام» على صفحة المنتج، وما بتنحط داخل السلة أو الدفع أو المراجعة.

## 1) وين

شاشة الطلب (قائمة الطلبات + تفاصيل الطلب):

| يظهر | المعنى |
|------|--------|
| توصيل فوري (`is_instant_delivery`) | كما هو — الزبون اختاره عند إنشاء الطلب |
| يوم ووقت التوصيل (`scheduled_delivery_at`) | الخيار الثاني. فاضي = ما في موعد محدد |

الفورم: تاريخ + ساعة ودقيقة.  
فراغ الحقل وحفظ = مسح الموعد (`null`).

الطلب المنتهي أو الملغى (`delivered` · `cancelled` · `cancelled_by_admin` · `returned_by_user`) ما ينفتح عليه الحفظ.

## 2) الحفظ

```http
PATCH /api/admin/orders/{orderId}/scheduled-delivery
Content-Type: application/json
Authorization: Bearer {admin_token}
```

```json
{
  "scheduled_delivery_at": "2026-09-28 16:30"
}
```

مسح الموعد:

```json
{
  "scheduled_delivery_at": null
}
```

الصيغة: `Y-m-d H:i` (يوم + وقت). بدون ثواني.

## 3) الرد

```json
{
  "status": true,
  "message": "تم تحديد يوم ووقت التوصيل.",
  "data": {
    "id": 12,
    "is_instant_delivery": false,
    "scheduled_delivery_at": "2026-09-28 16:30"
  }
}
```

| حقل | عرض |
|-----|-----|
| `scheduled_delivery_at` | `2026-09-28 16:30` أو `null` |
| `null` | لا سطر موعد على الكرت — لا تخترعوا وقتاً من `delivery_time` تبع المنتج |

نفس الحقل يرجع من `GET /api/admin/orders` و `GET /api/admin/orders/{id}/get_one`.

## 4) غلط vs صح

**غلط**

- حقل نص «3–5 أيام» على الطلب بدل تاريخ وساعة
- إخفاء الخيار لأن `is_instant_delivery` موجود
- اعتبار غياب الموعد باگ — `null` يعني لسا ما تحدد

**صح**

- خيار ثاني على الطلب: يوم + وقت
- الكرت يعرض الموعد بس إذا الإدارة حفظته
