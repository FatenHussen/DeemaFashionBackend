# الداشبورد — اختيار أكثر من بنر في قسم واحد (سلايدر)

> **أرسلوا هذا الملف لفريق الداشبورد فقط.**  
> **آخر تحديث:** 8 تشرين الأول 2026  
> Base: `/api/admin` + Admin token  
> **ما في تغيير على الـ API** — الباك كان يدعم عدة بنرات أصلاً  
> الشاشة: `/sections/pages/{pageId}/sections/create`  
> عرض البنر على الموقع: [`WEB_BANNER_REQUIRED_FIELDS.md`](./WEB_BANNER_REQUIRED_FIELDS.md)  
> سكرول البطاقات: [`DASHBOARD_BANNER_LIST_SCROLL.md`](./DASHBOARD_BANNER_LIST_SCROLL.md)

**المشكلة:** وقت إضافة قسم بانر للصفحة، القائمة كانت تسمح باختيار **بنر واحد فقط**.  
الأدمن كان يضيف قسمين منفصلين → البنرات تطلع تحت بعض على الموقع بدل سلايدر بأسهم.

**الإصلاح:** اختيار متعدد (checkbox) للبانرات داخل نفس القسم، مع إرسال كل المختارين في `item_ids`.

## 1) القاعدة

| الحالة | السلوك |
|--------|--------|
| نوع المحتوى = بنر | اختيار **متعدد** (checkbox) |
| باقي الأنواع (منتج، متجر، …) | اختيار **واحد** كما كان (ربط قسم موجود) |
| عدة بنرات في قسم واحد + `layout: slider` | الموقع يعرض سلايدر بأسهم جانبية |
| قسم بنر لكل بنر | البنرات تطلع **تحت بعض** — لا تسووا هيك |

الباك: `item_ids` مصفوفة `min:1` — ما في حدّ على عدد البنرات.

---

## 2) وين

| الشاشة | السلوك بعد الإصلاح |
|--------|---------------------|
| إضافة قسم للصفحة → نوع **بانر** | علّموا على أكثر من بنر؛ تظهر رسالة مساعدة أن السلايدر = كل البنرات في قسم واحد |
| نفس الشاشة → نوع غير بنر | اختيار واحد فقط |
| معاينة الصفحة / بطاقات البنر | بدون تغيير — كل عناصر `items` تظهر |

إذا الصفحة فيها قسم بنر مسبقاً: الأفضل تعديل القسم الموجود وإضافة البنرات له، مو إنشاء قسم بنر ثاني.

## 3) الـ payload

`POST /api/admin/pages/{page}/sections`

```json
{
  "type": "manual",
  "content_type": "banner",
  "name": { "ar": "بانر", "en": "Banner" },
  "layout": "slider",
  "variant": "horizontal",
  "position": "after",
  "item_ids": [
    { "item_id": 12, "order": 0 },
    { "item_id": 15, "order": 1 }
  ]
}
```

- `item_id` = معرف البنر من `GET /api/admin/banners`
- `order` = ترتيب الشريحة في السلايدر
- `layout` الافتراضي للبنر الجديد = `slider`

---

## 4) غلط vs صح

**غلط**

- قسم بنر فيه بنر 1 + قسم بنر ثاني فيه بنر 2 → تحت بعض على الموقع
- اختيار بنر واحد فقط ثم تكرار الإضافة لكل إعلان

**صح**

- قسم بنر **واحد** + بنرين (أو أكثر) في `item_ids` + `layout: slider` → سلايدر بأسهم

## 5) Checklist

- [ ] إضافة قسم → بانر: يمكن تعليم بنرين أو أكثر
- [ ] بعد الحفظ: قسم واحد على الصفحة وفيه كل البنرات المختارة
- [ ] الموقع: سلايدر بأسهم (مو بنرين تحت بعض)
- [ ] الأنواع الأخرى (منتج/متجر/…) ما زالت اختيار واحد
- [ ] ما في تغيير على جدول `/sections/banners` ولا على الـ API
