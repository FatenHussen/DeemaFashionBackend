الزبون يختار **يوم توصيل واحد** و**ساعة داخل ذلك اليوم**.  
ما في فترة زمنية، فما في عنوان **Start Date**.  
زر **حفظ الجدولة** يرسل الطلب. ما يبقى باهتاً بلا رد.

هذا مسار سلة التسوق (`POST /scheduled-baskets`).  
تأكيد السلة المخصصة (`confirm`) ما زال تاريخاً فقط — انظر آخر القسم.

ما تخلطوا مع:

| الحقل | وين | المعنى |
|--------|-----|--------|
| `delivery_time` على **المنتج** | صفحة المنتج | نص مثل «3–5 أيام» |
| `scheduled_delivery_at` على **الطلب** | كرت الطلب | موعد حدّدته الإدارة |
| `delivery_time` هنا | السلة المجدولة | ساعة اليوم `HH:mm` يختارها الزبون |

## 1) الشاشة

بعد «عرض تفاصيل الجدولة» → اختيار «جدولة التوصيل»:

| العنصر | المطلوب |
|--------|---------|
| عنوان فوق التقويم | **لا** تكتبوا Start Date / تاريخ البدء |
| التقويم | يوم واحد. الأسبوع من الأحد لليسار حتى مع العربية. الأيام قبل اليوم معطّلة |
| الوقت | حقل ساعة ودقيقة تحت التقويم. التسمية: **وقت التوصيل** |
| الملخص | التكرار · **تاريخ التوصيل** · **وقت التوصيل** · التوصيل التالي (نفس الساعة) |
| زر الحفظ | يرسل دائماً إلا أثناء الطلب. إذا ما في تكرار محمّل: رسالة، مو زر ميّت |

نصوص:

| عربي | إنجليزي |
|------|---------|
| تاريخ التوصيل | Delivery date |
| وقت التوصيل | Delivery time |
| حفظ الجدولة | Save schedule |

إذا التاريخ هو اليوم، الوقت من الآن فصاعداً. تاريخ لاحق: أي ساعة.

`GET /api/user/schedules` يرجع `name` نصاً (لغة الواجهة، وإلا العربي ثم الإنجليزي). لا تسقطوا الكرت إذا الاسم وصل ككائن `{ "ar", "en" }` — خذوا المتوفر.

## 2) الحفظ

```http
POST /api/user/scheduled-baskets
Authorization: Bearer {token}
Content-Type: application/json
```

```json
{
  "name": "أسبوعي",
  "schedule_id": 2,
  "is_active": true,
  "start_date": "2026-10-21",
  "delivery_time": "16:30",
  "items": [
    {
      "shop_product_variant_id": 25,
      "quantity": 2
    }
  ]
}
```

| الحقل | مطلوب | ملاحظة |
|--------|--------|--------|
| `name` | نعم | اسم الجدولة / اسم التكرار |
| `schedule_id` | نعم | من `GET /schedules` |
| `start_date` | نعم | `Y-m-d` · ≥ اليوم. هذا **يوم التوصيل** مو بداية مدى |
| `delivery_time` | لا على الـ API، **نعم بالواجهة** | `H:i` بدون ثواني. مثال `09:05` |
| `items` | نعم | عنصر واحد على الأقل |
| `items[].shop_product_variant_id` | أحدهما مع `product_id` | يكفي متغيّر المتجر. الباك يملأ `product_id` |
| `items[].product_id` | اختياري إذا المتغيّر موجود | |
| `category_id` | **لا** | لا ترسلوه ولا توقفوا الحفظ إذا المنتج بلا تصنيف |
| `is_active` | لا | الافتراضي `true` |

تعديل لاحق:

```http
PUT /api/user/scheduled-baskets/{id}
```

نفس `start_date` و `delivery_time` (`delivery_time` اختياري).

أخطاء 422:

| الحالة | الرسالة |
|--------|---------|
| تاريخ ماضي | تحقق `start_date` |
| وقت اليوم مضى | `وقت التوصيل لازم يكون من الآن فصاعداً` |
| عنصر بلا منتج وبلا متغيّر | `معرّف المنتج أو متغيّر المتجر مطلوب` |

## 3) الرد والعرض

`POST` / `GET /scheduled-baskets` / `GET /scheduled-baskets/{id}`:

```json
{
  "start_date": "2026-10-21",
  "delivery_time": "16:30",
  "next_run_date": "2026-10-21"
}
```

`delivery_time` = `null` إذا الجدولة قديمة بلا ساعة. لا تخترعوا وقتاً.

في قائمة «طلباتي المجدولة» اعرضوا التاريخ والساعة معاً: `21 Oct 2026 · 16:30`.

## 4) غلط vs صح

| غلط | صح |
|-----|-----|
| عنوان Start Date فوق التقويم | بلا عنوان. الملخص: تاريخ التوصيل |
| تاريخ من–إلى | يوم واحد + ساعة |
| زر حفظ باهت إذا التكرار ما انرسم | الزر يرسل، أو رسالة واضحة |
| إيقاف الحفظ لأن `category_id` فاضي | لا ترسلوا `category_id` |
| قلب أيام التقويم في العربية | الأسبوع من اليسار: أحد … سبت |
| خلط `delivery_time` المنتج («3–5 أيام») مع ساعة الجدولة | حقلان مختلفان |

### السلة المخصصة

`POST /api/user/schedules/{id}/custom-basket/confirm` **ما تغيّر**:

```json
{ "confirm_schedule": true, "start_date": "2026-10-21" }
```

لا ترسلوا `delivery_time` على هذا المسار.

## 5) Checklist

- [ ] لا نص Start Date
- [ ] تقويم يوم واحد، الأيام الماضية مقفلة، ترتيب الأيام ثابت
- [ ] اختيار ساعة ودقيقة، ويوم اليوم لا يقبل وقتاً ماضياً
- [ ] الملخص: تكرار + تاريخ التوصيل + وقت التوصيل
- [ ] حفظ الجدولة يضرب `POST /scheduled-baskets` مع `delivery_time`
- [ ] لا `category_id`
- [ ] العرض اللاحق يقرأ `delivery_time` أو يخفي الساعة إذا `null`
- [ ] تأكيد السلة المخصصة يبقى `start_date` فقط
