## 1) الفكرة

| مفهوم | المعنى |
|--------|--------|
| عملة التخزين | دائماً **USD** في قاعدة البيانات |
| عملة العرض الافتراضية | العمود `is_default` — يتحكم فيها الداشبورد |
| اختيار المستخدم | بعد ما يختار من التطبيق/الويب، يبقى على اختياره حتى لو تغيّر الافتراضي |

ما في إلا **عملة افتراضية نشطة واحدة**.

---

## 2) إضافة عملة جديدة وجعلها افتراضية

`POST /api/admin/currencies`

```json
{
  "code": "EUR",
  "name": { "en": "Euro", "ar": "يورو" },
  "symbol": "€",
  "exchange_rate": 0.92,
  "is_default": true,
  "is_active": true
}
```

| حقل | ملاحظة |
|-----|--------|
| `code` | 3 أحرف، يُحفظ Uppercase |
| `exchange_rate` | كم وحدة من هالعملة = **1 USD** |
| `is_default: true` | يلغي الافتراضية عن الباقي تلقائياً |

أو بعد الإنشاء: `PUT /api/admin/currencies/{id}` مع `{ "is_default": true }`.

---

## 3) قواعد الحماية

| عملية | النتيجة |
|--------|---------|
| تعطيل العملة الافتراضية | مرفوض |
| حذف العملة الافتراضية | مرفوض |
| `is_default: false` على الافتراضية الحالية بدون اختيار بديل | مرفوض |
| جعل عملة غير نشطة افتراضية | مرفوض |
| `is_default: true` على عملة ثانية | تنجح، والقديمة تصير غير افتراضية |

رسالة الخطأ: `currency_default_required` / `cannot_deactivate_default_currency`.

## 4) Checklist

- [ ] قائمة العملات تعرض `is_default` بوضوح

- [ ] عند إضافة عملة جديدة: خيار «اجعلها الافتراضية»
- [ ] لا تعطيل/حذف للسطر اللي `is_default: true`
