# الداشبورد — المستخدمين: `area_id` (توست «حقل area id غير موجود»)

> **الجمهور:** فريق الداشبورد  
> **تاريخ:** 21 تشرين الثاني 2026  
> **الباك:** جاهز بعد `git pull` — يحوّل `0` / `""` إلى `null`  
> Base: `PUT /api/admin/users/{id}` · `POST /api/admin/users` · `GET /api/admin/users`  
> نفس فكرة: [`DASHBOARD_PRODUCT_VENDOR_ID.md`](./DASHBOARD_PRODUCT_VENDOR_ID.md)

---

## هل نغيّر شيء في الداشبورد؟

نعم — عند تحديث كلمة المرور (أو أي تعديل مستخدم) **لا ترسلوا `area_id` فاضي**.

| الحالة | ماذا ترسلون | ماذا **لا** ترسلون |
|--------|-------------|---------------------|
| **تحديث كلمة المرور فقط** | `password` + `password_confirmation` | `area_id` · باقي الحقول غير المتغيّرة |
| **تعديل مستخدم + منطقة** | `area_id` = رقم منطقة موجود | `area_id: 0` · `""` · اسم المنطقة كنص |
| **بدون منطقة** | احذفوا المفتاح، أو `null` | `0` |

---

## ماذا كان الخطأ؟

من صفحة `/users` → «تحديث كلمة المرور» يظهر توست أحمر:

```text
حقل area id غير موجود
```

**مو** فشل كلمة المرور. الطلب يروح على `PUT /api/admin/users/{id}`، والجسم كان يرسل `area_id: 0` (سلكت المنطقة فاضي).  
`nullable` ما يعتبر `0` = فارغ → `exists:areas,id` يفشل ويوقف التحديث كله (بما فيه الباسورد).

عمود «منطقة» فاضي في الجدول = المستخدم بلا `area_id` — طبيعي.

---

## القائمة vs التفاصيل

| Endpoint | الحقل |
|----------|--------|
| `GET /users` (قائمة) | صار فيه `area_id` + `area` (الاسم) |
| `GET /users/{id}` | `area_id` |

إذا الفورم يتعبّى من القائمة: استخدموا **`area_id` الرقمي**، مو نص `area`.

---

## Payload

```text
# ✅ تحديث كلمة المرور فقط
password=NewPass123!
password_confirmation=NewPass123!

# ✅ تعديل منطقة
area_id=5

# ✅ مسح المنطقة (اختياري)
area_id=null
```

```js
// ❌ لا
body.area_id = selectedAreaId || 0;
formData.append('area_id', '');
body.area_id = user.area; // اسم المنطقة كنص

// ✅ نعم — تحديث باسورد فقط
await api.put(`/users/${id}`, {
  password,
  password_confirmation,
});

// ✅ نعم — تعديل منطقة فقط إذا مختارة
const payload = { name, phone, /* … */ };
if (areaId) payload.area_id = areaId;
// بدون مفتاح = لا تغيّروا المنطقة الحالية
```

## توست الأخطاء (موصيّ به)

422 يرجع:

```json
{
  "status": false,
  "message": "خطأ في التحقق",
  "errors": {
    "area_id": ["حقل area id غير موجود"]
  }
}
```

اعرضوا **`errors` مرة واحدة** (flat unique). لا توست لـ `message` إذا نفس النص موجود داخل `errors`.

بعد `git pull` على الباك: `area_id: 0` / `""` ينمسحوا تلقائياً. الداشبورد الأفضل يبقى: **لا ترسلوا المفتاح إذا فاضي**.

---

## Checklist

- [ ] تحديث كلمة المرور: `password` + `password_confirmation` فقط — **بدون** `area_id`
- [ ] لا `area_id=0` ولا `""` ولا اسم منطقة كنص
- [ ] تعديل المنطقة: رقم من `areas` فقط؛ القائمة تعطي `area_id`
- [ ] توست 422: رسائل `errors` مرة واحدة (لا توستان بنفس النص)

**الباك جاهز. الداشبورد: لا ترسلوا `area_id` فاضي مع تحديث الباسورد.**
